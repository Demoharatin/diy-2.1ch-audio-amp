# diy-2.1ch-audio-amp
# Двошарова материнська плата та 3D-корпус для аудіосистеми 2.1

Проєкт двошарової друкованої плати (`100 × 100 мм`) та розбірного 3D-корпусу для підсилювача потужності формату 2.1 із мікрофонним передпідсилювачем.

## Основні характеристики
* **Вхідне живлення:** `20 В` DC (із котушкою `L1` та фільтрувальним конденсатором `C1`).
* **Стабілізатори напруги:** лінійні `LM7812` (`+12 В`) та `LM7809` (`+9 В`) у корпусах `TO-220`.
* **Підсилювальний тракт:** два модулі підсилювачів класу D (`TPA3118`) та перевернуті модулі передпідсилювачів (`AD828A`) на нижньому боці плати.
* **Корпус:** спроєктовано в Onshape під 3D-друк (нижня частина зі стійками висотою 15 мм під нижні елементи + верхня вентиляційна кришка).
